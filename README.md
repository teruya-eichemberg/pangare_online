# PANGARÉ — protótipo online

Este pacote contém o protótipo visual e o motor de jogo do Pangaré, preparado para partidas de 2 a 4 pessoas e bots.

## Importante sobre o link público

O pacote está pronto para publicação, mas esta conversa não possui um serviço de hospedagem público nem credenciais de uma conta de hospedagem. Por isso não é possível gerar, daqui, um endereço público permanente do tipo `https://pangare...` sem fazer a publicação em um serviço externo.

O projeto inclui:
- sala por código;
- até 4 jogadores;
- bots;
- 5 pangarés e 3 símbolos;
- push your luck;
- acidentes;
- bônus de 2/3 pangarés iguais;
- Cenoura e Galinha;
- apostas 1º–5º;
- fim de corrida aos 7;
- pontuação.

## Publicação

1. Suba esta pasta para um serviço Node.js (por exemplo Render, Railway, Fly.io ou outro host que aceite Node).
2. Execute `npm install`.
3. Execute `npm start`.
4. O serviço usa a porta indicada por `PORT` ou 3000.
